# content-recommender
### Narrative-Based Content Recommendation System

#### Video Demo: ruby to add url herel

#### Description:

A command-line tool that recommends books and movies based on deeper
narrative similarities — themes, tone, mood, pace, and complexity —
rather than just genre. Users select 1-3 items they enjoy, and the
system builds a preference profile to find content that feels similar.

The recommendation engine converts each item's attributes into a binary
feature vector and uses cosine similarity to score every remaining item
against the user's aggregated profile. Results are ranked by match
percentage with explanations of why each item was recommended.
